# Book Roulette (Lab 6 · Favorites Roulette)

Single-screen iOS app: tap the button and get a random card (cover, title, description) from my 10 favorite books. The same book never shows twice in a row.

- Swift, UIKit, Storyboard, **no Auto Layout** (no constraints in any storyboard)
- 10 favorites stored as an array of a `Favorite` struct
- Custom LaunchScreen and AppIcon (1024×1024, no transparency)
- Covers are original illustrations created for this project
